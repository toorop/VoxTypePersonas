# Project Working Agreement

- Write all documentation and all code comments in English.
- Do not create commits or push changes without the user's explicit prior approval.
- Develop the project incrementally, using small, focused steps.
- After completing each step, ask the user whether to continue. Wait for the user to validate the result and say "on continue" before starting the next step.
- If a commit would be appropriate, tell the user and ask for approval before creating it.
- Only push changes when the user explicitly requests a push.
